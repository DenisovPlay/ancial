# Полировка интерфейса сообществ и групповых звонков

## Цель

Исправить четыре замечания дизайн-аудита без изменения продуктового поведения:

1. заменить системные подтверждения удаления и модерации на стандартные модальные окна Zypo;
2. учесть динамическую высоту viewport и safe area в групповом звонке;
3. заменить временные текстовые обозначения каналов и микрофона на SVG-иконки;
4. локализовать типы каналов и даты журнала действий.

## Подтверждения действий

Существующий `ConfirmDeleteModal` переиспользуется в редакторах каналов, ролей и участников. Каждый экран хранит только описание ожидающего подтверждения и идентификаторы действия. Отмена очищает ожидающее действие. Подтверждение сначала закрывает окно, затем запускает существующий API-вызов; ошибки по-прежнему показываются через `useNotification`.

Подтверждение требуется для:

- удаления категории;
- удаления канала;
- удаления роли;
- исключения участника;
- блокировки участника.

Mute и unmute остаются немедленными обратимыми действиями.

## Групповой звонок

Полноэкранные загрузочные состояния используют `min-h-dvh` вместо `h-screen`. Верхняя шапка и нижняя панель получают отступы с `env(safe-area-inset-top)` и `env(safe-area-inset-bottom)`. Визуальный дизайн звонка и маршрут 1-на-1 не меняются.

## Иконки

Для каналов используется существующий спрайт `/icons.svg`:

- текстовый канал — `IC-chats`;
- объявления — `IC-news`;
- голосовой канал — `IC-call`.

Иконка канала оформляется отдельным маленьким компонентом, чтобы список и карточка выбранного канала не расходились. Статус микрофона в плитке звонка отображается SVG-иконкой с перечёркиванием для выключенного состояния. Новый символ в общий спрайт не добавляется, поэтому Service Worker обновлять не требуется.

## Локализация

Редактор каналов показывает существующие переводы `community_channel_text`, `community_channel_announcement` и `community_channel_voice` вместо значений API. Даты аудита форматируются через `Intl.DateTimeFormat`; локаль выбирается из текущего словаря `lang.langname`, с безопасным fallback на русский. Некорректная или пустая дата отображается исходной строкой, чтобы журнал не терял данные.

## Проверка

- unit-тесты для выбора иконки, локализованного типа и форматирования дат;
- существующие тесты community permissions/cache/group calls;
- ESLint и TypeScript;
- React Doctor по изменённым файлам;
- production-сборка Next.js;
- `git diff --check`.

Все изменения и коммиты остаются локальными. Push и синхронизация с GitHub запрещены.
